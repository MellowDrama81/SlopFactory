# SlopFactory user documentation

SlopFactory is a local-first media library being built for Windows and Android. This documentation describes behavior that is implemented and verified in the current development build. Planned provider connections and AI generation are not available yet.

## Available documentation

- [Getting started](getting-started.md)
- [Managing the local library](library.md)

## Current development status

The current build can create its default local library, import, duplicate, and edit supported text files as independent managed copies, organize files in folders, view supported UTF-8 text, raster images, and sanitized SVG, attach typed user metadata, create and display directed file links, search, review, bulk-restore, or permanently delete recycle-bin aggregates, and explicitly scan the local library for integrity issues. Windows and Android projects both compile from the same source and use the same library format.
